# 阶段 3/4 设计（多空辩论 v1 · 动态风险预算 meta v1）

> 依据 docs/AGENT_ROADMAP.md P2 项。两个版本都选"渐进式"：先做只影响
> 信息流/参数、不动交易执行语义的 v1，跑 1-2 周出数据再升级 v2。

## 阶段 3 · 多空辩论 v1：分歧检测 + 显式回应

**决策**：不做"分歧→arbiter 合成→执行"（盘中改执行权 = 把闸门搬到模型手里，
风险不可控）。v1 在信息层闭环：

- 系统检测：同一自然日内，不同 agent 对**同一标的**给出相反方向
  （sell vs buy/watch-加仓）→ 生成【分歧】标注。
- 注入：相关 agent 的下一轮分析提示词自动带上
  「⚠️ 与 X 分歧：X 认为 …(理由摘要)；请在你的结论里明确回应：证据是否
  覆盖其理由，仍坚持则写明为什么」——让对抗视角进决策上下文，但执行权不变。
- 落盘：分歧事件记 `logs/debates/{date}.jsonl`（2 周后出"分歧标的后续走势"
  统计 → 谁更常对），即路线图验收数据。

**v2（数据充足后）**：分歧且任一方为高置信大动作 → 单次廉价 LLM arbiter
仅作建议（仍不代执行权），输出供人审。

## 阶段 4 · 风险预算 meta v1：确定性规则内核

**输入**（全部已有数据源）：
- 波动率：上证/沪深300 近 20 日收益率标准差（年化近似）
- 回撤：分账总净值近 20 日最大回撤（logs/live_equity 日终序列）
- 情绪温度：Fuyao 涨停池家数/连板高度 + 大盘三态
- 现金/杠杆现状：账本

**规则内核**（阈值可配置，收敛优先）：
| 状态 | leverage_max | per_stock | max_new_buys |
|---|---|---|---|
| 平静（波动低+无回撤+情绪中性） | 1.5 | 0.20 | 3 |
| 谨慎（波动↑ 或 回撤>3% 或 情绪偏冷） | 1.2 | 0.15 | 2 |
| 防守（波动显著↑ 且 回撤>5%，或 情绪退潮/跌停潮） | 1.0 | 0.10 | 1 |

- 产出：`configs/risk_budget.json`（闸门运行时读取）+ `logs/budget/{date}.json`
  （含触发因素与说明文本，LLM 解释放 v2）。
- 恢复：每交易日 09:10 北京 由 cron 依当前状态重算（非"手动复位"——
  状态恢复即自动放松，但单日只允许收紧一次防抖动：同日不重复放大）。
- 接线：live_hourly_analysis / leverage_guard 在进程启动时读该配置覆盖
  模块常量（LEVERAGE_MAX/PER_STOCK_PCT/MAX_NEW_BUYS/LEVERAGE_TRIM_TO），
  分钟级守护与买入闸门即刻生效——不改闸门逻辑，只换参数源。

**验收**：极端日演练（模拟大跌日）预算落至防守档且强平守护按新杠杆执行；
正常日恢复 1.5 档。
