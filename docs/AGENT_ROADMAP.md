# 交易智能体演进路线图（A股跑通 → 多市场复刻）

> 定位：从"受约束的自主交易智能体"（现状）演进到"自我进化的多市场智能体组织"。
> 原则：**公共智能体内核 + 市场适配包**——内核（工作法/记忆/假设库/辩论/风险预算）
> 全部市场无关；市场差异收敛到一层"市场包"（broker/时段/规则/数据源/技能子集）。

## 阶段 0 · 现状基线（已达成 ✅）

| 构件 | 状态 |
|---|---|
| 感知 | 桥实时快照/五档/跳空/涨速/量比 + QuantDB 全维 + L2 因子 + 新闻情绪 + 情绪温度（Fuyao 涨停池） |
| 推理 | 三 agent 角色分化（快枪手/研究员/消息面），四段式输出，时间盒 |
| 行动 | 决策 JSON → 闸门 → 通达信桥实盘下单 → 分账记账；watch 条件位分钟哨兵 |
| 记忆 | 上轮决策 / market_memory 读写 / 近 7 日成交回顾 |
| 风控轨道 | 1.5× 强平守护（分钟级）/ T+1 / 额度红线 / 拒单延期重放 / 行情停更硬闸 |

## 阶段 1 · 自我进化闭环（P0，约 1 周）

**目标**：盘后 agent 自动复盘自己的盈亏归因，把经验写进记忆与假设库——不再靠人手动沉淀。

- **触发**：cron 北京 15:30/16:00，每 agent 一轮复盘任务（复用 dsh agent 管线）。
- **输入**（全部已有）：当日该 agent 成交流水 + 决策快照 + 盘面状态序列 + 净值曲线 + 新闻。
- **任务模板**：逐笔归因（这笔赚/亏，当初理由是否兑现？）→ 提炼 1-3 条经验/教训 →
  `append_memory` 沉淀 → 产出**明日预案**（持仓逐只：加减/不动条件）。
- **产出物**：`logs/review/{agent}/{date}.md` + memory 更新 + 策略假设提交（对接阶段 2）。
- **验收**：连续 5 个交易日每 agent 一份复盘、memory 增长、次日分析提示词中可见引用。

## 阶段 2 · 策略假设库（P1，1-2 周）

**目标**：把"缩量洗盘""利好出货"这类定性变成**带历史胜率的可验证假设**，agent 引用时自带证据。

- **存储**：`configs/hypotheses/*.json`（触发条件/方向/验证窗口/胜率/样本数/状态
  proposed→verified→deprecated）。
- **验证器**：quantdb 历史日线事件研究脚本——对每条假设在近 2 年回放统计
  触发后 1/3/5 日收益分布 → 胜率标签。
- **注入**：分析提示词引用假设时带 `[胜率 63% · n=38 · 近30日有效]`；无标签的定性
  一律标注"未验证"。
- **治理**：复盘 agent（阶段 1）是唯一提交入口；连续 2 次失效自动降级 deprecated。
- **首批 5 条**：缩量洗盘 / 利好出货 / 放量滞涨 / 低吸反抽 / 连板退潮。

## 阶段 3 · 多空辩论机制（P2）

**目标**：决策合成前引入对抗视角，防单模型过度自信。

- **机制**：检测到方向分歧或大动作时触发——flash（进攻）vs pro（防守）各自出
  立场陈述（复用四段式①③段）→ arbiter（廉价 LLM 单次调用）按"证据强度×风控"
  合成最终决策；分歧不可调和 → 降级为 watch。
- **成本控制**：只在分歧信号出现时辩论，常规轮次跳过。
- **验收**：分歧触发率、合成决策与单模型决策的胜率对比报告（跑 2 周出数据）。

## 阶段 4 · 动态风险预算 meta-agent（P2，与阶段 3 并行）

**目标**：风险额度不再静态，由独立 meta-agent 按市场状态动态分配。

- **输入**：组合波动率 / 当前回撤 / 持仓相关性 / 情绪温度（Fuyao 涨停池+连板高度）/
  大盘三态（已有）。
- **输出**：`configs/risk_budget.json`——各分账的 LEVERAGE_MAX、单票上限、
  当日最大新动作数；强平守护与买入闸门**读取该文件**（已有闸门代码只换配置源）。
- **规则内核**（确定性，LLM 只做解释）：波动率↑ 或 回撤加深 → 额度自动收紧；
  情绪退潮（连板高度塌陷）→ 新开仓暂停。
- **验收**：模拟极端日（情绪骤变）额度自动收紧且强平守护按新额度执行。

## 阶段 5 · 多市场复刻（P3，A股验证后）

**复刻公式 = 公共内核 + 市场包**：

| 层 | 内容 | A股（已有） | HK | US |
|---|---|---|---|---|
| 内核 | 工作法/四段式/记忆/假设库/辩论/风险预算 | ✅ | 直接复用 | 直接复用 |
| broker | tdx-bridge | 富途 OpenD（已有 broker+技能） | IBKR Gateway（容器已备） |
| 规则 | T+1/涨跌停/100 股 | T+0/可做空/最小单位 | T+0/1 股/盘前盘后 |
| 数据 | 桥+QuantDB+Fuyao | 富途 API（行情/L2） | IBKR+AlphaVantage |
| 技能 | 全 A 技能 + ths-fuyao | futuapi 技能 | ibkr-cli/tigeropen 技能 |

- **第一个复刻对象：HK**（broker 与技能最齐）。步骤：把 live_hourly_analysis 的
  工作法/记忆/假设库调用参数化为 `market` → 用富途 broker 替换桥 → 分账按 HKD。
- **US 第二**（ib-gateway 容器已配置，2FA 流程需人工首次登录）。
- **验收**：单市场 5 个交易日无人干预跑通全链路（分析→下单→记账→复盘）。

先在 A股把纪律跑实，再谈复制与升级。
