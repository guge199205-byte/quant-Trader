## 三、架构升级规划

### 目标架构

```
┌─────────────┐   ┌──────────────┐   ┌──────────────┐   ┌──────────────┐
│  nof0 前端   │──▶│  FastAPI API  │──▶│  agent_data   │◀──│   main.py    │
│ (8080,响应式)│   │  (8090)       │   │  (JSONL 落盘) │   │  交易主程序   │
└─────────────┘   └──────┬───────┘   └──────────────┘   └──────┬───────┘
                         │                                     │ MCP
                    ┌────▼─────┐                         ┌────▼─────┐
                    │ SQLite   │                         │ 8100-8103│
                    │ 元数据    │                         │ 4 服务    │
                    └──────────┘                         └──────────┘
```

关键改动：
1. **API 层**（FastAPI，端口 8090）：实时读 `data/agent_data/` → JSON 响应，前端 `data-loader.js` 改从 API 取数（替代静态快照复制）
2. **SQLite 元数据**：模型注册、交易日进度、任务状态（可选，初期 JSONL 够用）
3. **前端实时化**：轮询/SSE 推送交易进度

### 阶段划分

**P0（1 周内）**：API 层 + 前端实时取数、bug 1/2 根治、search key 验证
**P1（2-3 周）**：券商接入（见下）、模拟盘打通
**P2（1 个月）**：实盘风控、多市场支持、前端完善

## 四、券商接入方案（复用 quantmind 资产）

quantmind 已有对接资产（`~/projects/quantmind`）：

| 券商 | 现有资产 | 复用方式 |
|------|---------|---------|
| 通达信 TDX | `backend/services/trade/services/tdx_account_sync_task.py`、`tdx_signal_push_service.py`、`routers/tdx_l2.py`；skills/tdx-live-trading；8550 桥 token | 桥接协议抽取为 broker adapter：行情（日K/周K）已可用，下单走 TDX 模拟盘 API |
| 富途 Futu | skills/futuapi、skills/install-futu-opend（OpenD 网关） | 装 OpenD → futuapi 封装为 adapter（行情/下单/持仓全量支持） |
| 老虎 Tiger | skills/tigeropen（Python SDK） | tigeropen 封装为 adapter |
| IBKR | 无（需新接） | ib_insync（现 ib_async）封装 adapter；注意国内网络需 IB 网关 |

### 统一 Broker 抽象层（在 BayMax 项目内新增）

```
agent_tools/brokers/
├── base.py          # Broker 接口: get_quote/get_kline/place_order/get_positions/cancel_order
├── tdx_bridge.py    # 通达信桥（复用 quantmind bridge 协议）
├── futu_bridge.py   # 富途 OpenD（futuapi）
├── tiger_bridge.py  # 老虎证券（tigeropen）
├── ibkr_bridge.py   # IBKR（ib_async）
└── sandbox.py       # 模拟盘（现 tool_trade.py 本地逻辑，作为默认 broker）
```

接入点：
1. `agent_tools/tool_trade.py` / `tool_get_price_local.py` 增加 `broker` 参数，按配置路由到对应 adapter
2. `configs/*.json` 增加 `broker: "sandbox" | "tdx" | "futu" | "tiger" | "ibkr"` 字段
3. 环境变量：`TDX_BRIDGE_URL`、`FUTU_OPEND_HOST`、`TIGER_*`、`IBKR_*`（quantmind `.env` 已有部分）
4. 安全：实盘 broker 需二次确认 + 风控（单笔限额/日亏损上限），模拟盘默认

### 风险提示
- 实盘接入涉及真金白银，建议先只接通"模拟/paper"档位（TDX 模拟盘、IBKR paper、富途仿真）
- 行情源区分：TDX 桥已有数据能力（1221 根日K），分钟线不支持（桥限制），富途/IBKR 可补
